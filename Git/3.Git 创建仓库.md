# Git 创建仓库

通常有两种获取 Git 项目仓库的方式：

- 将尚未进行版本控制的本地目录转换为 Git 仓库；

- 从其他服务器克隆一个已存在的 Git 仓库。

## 本地仓库搭建

使用 `git init` 命令初始化 Git 仓库：

```bash
# 使用当前目录作为 Git 仓库
git init

# 使用指定目录作为 Git 仓库（目录不存在会自动创建）
git init <dir>
```

该命令将会在目录中生成一个 `.git` 目录，该目录包含 Git 仓库的所有必需文件，其他的项目目录保持不变。

此时仅完成初始化操作，项目文件尚未被跟踪。

## 克隆远程仓库

使用 `git clone` 命令克隆现有的远程仓库：

```bash
# 克隆仓库（[dir] 为可选选项，缺省则默认使用远程仓库名作为本地目录名）
git clone <repo> [<dir>]
```
> [!NOTE]
> 
> Git 克隆的是该仓库的几乎所有数据，而不仅仅是当前最新的文件。执行 `git clone` 命令时，默认配置下远程 Git 仓库中的每一个文件的每一个版本都将被拉取下来，因此即使服务器磁盘损坏，通常也可以使用任何克隆副本来重建仓库。
