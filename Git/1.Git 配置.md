# Git 配置

Git 使用 `git config` 命令来设置控制 Git 外观和行为的配置变量。

## 核心配置变量

### 用户信息

用户名（`user.name`）和邮箱（`user.email`）是用于标识提交者身份的核心配置变量。每次执行提交时，Git 都会读取这两个变量，并将其永久嵌入该次提交记录中，不可更改。

配置用户信息的命令如下：

```bash
git config --global user.name "<user-name>"
git config --global user.email <user-email>
```

### 换行符处理

换行符转换变量（`core.autocrlf`）用于解决跨平台开发时由于系统默认换行符不同（Windows 使用 CRLF，macOS/Linux 使用 LF）导致的代码差异冲突。

- **Windows 环境**（提交时转换为 LF，检出时转换为 CRLF）：

  ```bash
  git config --global core.autocrlf true
  ```

- **macOS/Linux 环境**（提交时转换为 LF，检出时不转换）：

  ```bash
  git config --global core.autocrlf input
  ```

### 中文编码处理

路径引用变量（`core.quotepath`）。默认情况下，Git 在输出中文时使用八进制字符串转义，关闭此变量可正常显示中文路径：

```bash
git config --global core.quotepath false
```

## 作用域与存储位置

Git 的所有配置变量都存储在以下三个不同的位置：

1. **`/etc/gitconfig`**

   系统级配置文件，适用于系统中所有用户及仓库。使用 `git config` 时附带 `--system` 选项，会读写该文件中的配置变量。修改此文件需要管理员或超级用户权限。

2. **`~/.gitconfig` 或 `~/.config/git/config`**

   用户级配置文件，仅适用于当前登录用户。使用 `git config` 时附带 `--global` 选项，会读写该文件中的配置变量。

3. **当前仓库的 `.git/config`**

   仓库级配置文件，仅针对当前仓库。使用 `git config` 时附带 `--local` 选项（或不带任何选项），会读写该文件中的配置变量。

同一个配置变量可以同时存在于多个级别中，每个级别的配置会覆盖上一级别的配置，例如 `.git/config` 中的变量会覆盖 `/etc/gitconfig` 中的设置。

## 查看配置

- **查看所有配置**：

  列出所有的配置变量及其所在文件（包含因层级关系被覆盖的记录）。

  ```bash
  git config --list --show-origin
  ```

- **查看单项配置**：

  直接查询某个特定配置项当前的最终生效值。

  ```bash
  git config <config-name>
  ```

## 其他配置变量

### 网络代理

在克隆或推送远程仓库时，若遇到网络连接受阻，可通过配置 HTTP/HTTPS 代理，将 Git 的网络请求转发至本地 VPN 或代理软件的监听端口，以解决访问限制问题。

- **设置代理**：

  ```bash
  # 设置全局 HTTP 代理
  git config --global http.proxy <proxy-url>

  # 设置全局 HTTPS 代理
  git config --global https.proxy <proxy-url>
  ```

  > [!note]
  > 
  > `<proxy-url>` 通常为 `http://127.0.0.1:<port>` 或 `socks5://127.0.0.1:<port>`。

- **取消代理**：

  ```bash
  git config --global --unset http.proxy
  git config --global --unset https.proxy
  ```

- **仅针对特定域名设置代理**：

  如果只想对 GitHub 设置代理，而不影响其他平台，可指定域名配置：

  ```bash
  git config --global http.https://github.com.proxy <proxy-url>
  ```

### 命令别名

可以通过 `git config` 命令来为其他命令设置一个别名。

- **为 Git 命令设置别名**：

  ```bash
  # 设置 log -1 HEAD 的别名为 last
  git config --global alias.last 'log -1 HEAD'
  ```

  设置后，`git last` 等同于 `git log -1 HEAD`。

- **为外部命令设置别名**：

  以在命令前面加入 `!` 符号为外部命令设置别名。

  ```bash
  # 设置 gitk 的别名为 visual
  git config --global alias.visual '!gitk'
  ```

  设置后，`git visual` 等同于 `gitk`。
