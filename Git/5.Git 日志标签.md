# Git 日志标签

## Git 日志

使用 `git log` 命令可以查看提交历史，它会显示提交的完整 SHA-1 哈希值、作者信息、提交时间以及提交说明。

### 常用显示格式

| 选项        | 说明                                                     |
| :---------- | :------------------------------------------------------- |
| `--oneline` | 将每次提交以单行形式呈现，仅显示哈希值前缀和提交说明     |
| `--graph`   | 在日志旁以图形显示分支与合并历史                         |
| `-p`        | 按补丁格式显示每次提交引入的差异                         |
| `--stat`    | 显示每次提交的文件修改统计信息，包括修改的文件及增删行数 |

### 常用过滤选项

| 选项                 | 说明                                           |
| :------------------- | :--------------------------------------------- |
| `-<n>`               | 仅显示最近的 n 条提交                          |
| `--author="<regex>"` | 仅显示作者匹配该正则表达式的提交               |
| `--grep="<regex>"`   | 仅显示提交说明中包含该正则匹配项的提交         |
| `-S "<string>"`      | 仅显示该字符串在文件中出现次数发生改变的提交   |
| `-G "<regex>"`       | 显示修改内容中包含该正则匹配项的提交           |
| `--no-merges`        | 不显示合并提交                                 |
| `-- <path>`          | 仅显示指定文件或目录的提交（必须放在命令最后） |

### 操作对象与区间

| 选项       | 说明                               |
| :--------- | :--------------------------------- |
| `<branch>` | 查看指定分支历史（默认为当前分支） |
| `A..B`     | 查看在 B 中但不在 A 中的提交       |
| `--all`    | 查看所有分支的历史                 |

最常用形式：`git log --oneline --graph --all`

## Git 标签

Git 可以给历史中的某一个提交打上标签，以示重要。通常使用此功能来标记发布节点（如 `v1.0`、`v2.0` 等）。

## 标签类型

Git 支持两种标签：**轻量标签（Lightweight）**和**附注标签（Annotated）**。

- **轻量标签**：本质上是将特定提交的哈希值存储到一个文件中，不保存任何其他信息，仅仅是一个特定提交的引用。

- **附注标签**：是存储在 Git 数据库中的一个完整对象，包含打标签者的用户名、邮箱、打标签的日期以及标签说明，并支持使用 GPG 进行加密签名与校验，官方推荐使用附注标签。

## 标签操作

- **列出标签**：

  ```bash
  # 列出已有的标签
  git tag
  
  # 使用 -l 或 --list 选项可按照特定的模式查找标签
  git tag -l "<pattern>"
  ```

  > [!note]
  > 
  > `<pattern>` 支持标准 Shell 通配符（即标准 glob 模式）。

- **创建标签**：

  ```bash
  # 给当前提交创建轻量标签（不加任何选项，直接指定标签名）
  git tag <tag-name>
  
  # 给当前提交创建附注标签（使用 -a 选项，并使用 -m 添加说明）
  git tag -a <tag-name> -m "<message>"
  
  # 补打历史标签（需指定提交的哈希值）
  git tag -a <tag-name> -m "<message>" <commit-hash>
  ```

- **查看标签**：

  查看特定标签的具体信息与对应的提交记录。

  ```bash
  git show <tag-name>
  ```

  对于轻量标签，该命令仅显示对应的提交说明；而对于附注标签，可以显示打标签者的用户名、邮箱、打标签的日期以及标签说明，然后显示对应的提交说明。

- **删除标签**：

  ```bash
  git tag -d <tag-name>
  ```

**注**：标签本质上属于 "引用（Ref）"，是指向特定提交哈希值的指针。
