# $z$ 变换与拉普拉斯变换

## 从拉普拉斯变换到 $z$ 变换

连续时间信号 $x(t)$ 的抽样后信号 $x_s(t)$ 的双边信号拉普拉斯变换为：

$$
X_s(s) = \sum_{n=-\infty}^{\infty} x(nT) e^{-nTs}
$$

令 $z = e^{Ts}$ 或 $s = \dfrac{1}{T} \ln z$，上式右端即为 $x[n]$ 的 $z$ 变换定义式。

$z$ 变换与拉普拉斯变换之间的关系：

$$
X(z) = \left. X_s(s) \right|_{s = \frac{1}{T} \ln z}
$$

如果上述函数 $x(t)$ 为连续时间系统的冲激响应 $h(t)$，则有：

$$
H(z) = \left. H_s(s) \right|_{s = \frac{1}{T} \ln z}
$$

## $s$ 平面和 $z$ 平面之间的映射关系

将 $z = r e^{\mathrm{j}\Omega}$ 和 $s = \sigma + \mathrm{j}\omega$ 代入 $z = e^{Ts}$ 或 $s = \dfrac{1}{T} \ln z$ 中得：

$$
r = e^{\sigma T}; \quad \Omega = \omega T
$$

|      $s$ 平面（$s = \sigma + \mathrm{j}\omega$）       |     $z$ 平面（$z = r e^{\mathrm{j}\Omega}$）      |
| :----------------------------------------------------: | :-----------------------------------------------: |
|         坐标原点（$\sigma = 0$，$\omega = 0$）         |                 实轴上点 $z = 1$                  |
|          实轴（任意 $\sigma$，$\omega = 0$）           |         正实轴（任意 $r$，$\Omega = 0$）          |
|          虚轴（$\sigma = 0$，任意 $\omega$）           |         单位圆（$r = 1$，任意 $\Omega$）          |
|      左半 $s$ 平面（$\sigma < 0$，任意 $\omega$）      |        单位圆内（$r < 1$，任意 $\Omega$）         |
|      右半 $s$ 平面（$\sigma > 0$，任意 $\omega$）      |        单位圆外（$r > 1$，任意 $\Omega$）         |
| 平行于虚轴的直线（$\sigma = \sigma_0$，任意 $\omega$） |     圆（$r = e^{\sigma_0 T}$，任意 $\Omega$）     |
| 平行于实轴的直线（任意 $\sigma$，$\omega = \omega_1$） | 始于原点的射线（任意 $r$，$\Omega = \omega_1 T$） |
| 水平带状区域（$\lvert\omega\rvert < \dfrac{\pi}{T}$，任意 $\sigma$） | 整个 $z$ 平面（任意 $r$，任意 $\Omega$） |
