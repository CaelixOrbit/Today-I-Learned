# 常见信号的傅里叶变换

|                                  信号                                   |                               傅里叶变换                               |
| :---------------------------------------------------------------------: | :--------------------------------------------------------------------: |
|                               $\delta(t)$                               |                                  $1$                                   |
|                                   $1$                                   |                          $2\pi\delta(\omega)$                          |
|             $\dfrac{\mathrm{d}^k}{\mathrm{d}t^k}\delta(t)$              |                         $(\mathrm{j}\omega)^k$                         |
|                            $\delta(t - t_0)$                            |                      $e^{-\mathrm{j}\omega t_0}$                       |
|                       $e^{\mathrm{j}\omega_0 t}$                        |                    $2\pi\delta(\omega - \omega_0)$                     |
|                            $\cos \omega_0 t$                            |      $\pi[\delta(\omega + \omega_0) + \delta(\omega - \omega_0)]$      |
|                            $\sin \omega_0 t$                            | $\mathrm{j}\pi[\delta(\omega + \omega_0) - \delta(\omega - \omega_0)]$ |
| $u\left(t + \dfrac{\tau}{2}\right) - u\left(t - \dfrac{\tau}{2}\right)$ |       $\tau \operatorname{Sa}\left(\dfrac{\omega\tau}{2}\right)$       |
|                             $e^{-at} u(t)$                              |                   $\dfrac{1}{a + \mathrm{j}\omega}$                    |
|                        $e^{-a \lvert t \rvert}$                         |                      $\dfrac{2a}{\omega^2 + a^2}$                      |
|                            $t e^{-at} u(t)$                             |                 $\dfrac{1}{(a + \mathrm{j}\omega)^2}$                  |
|               $e^{-at} \cdot \cos \omega_0 t \cdot u(t)$                | $\dfrac{a + \mathrm{j}\omega}{(a + \mathrm{j}\omega)^2 + \omega_0^2}$  |
|               $e^{-at} \cdot \sin \omega_0 t \cdot u(t)$                |       $\dfrac{\omega_0}{(a + \mathrm{j}\omega)^2 + \omega_0^2}$        |
