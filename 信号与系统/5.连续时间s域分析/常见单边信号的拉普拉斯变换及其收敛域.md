# 常见单边信号的拉普拉斯变换及其收敛域

|                              信号                               |                   拉普拉斯变换                    |       收敛域       |
| :-------------------------------------------------------------: | :-----------------------------------------------: | :----------------: |
|                           $\delta(t)$                           |                        $1$                        | $\sigma > -\infty$ |
|                        $\delta(t - t_0)$                        |                   $e^{-s t_0}$                    | $\sigma > -\infty$ |
|                             $u(t)$                              |                  $\dfrac{1}{s}$                   |    $\sigma > 0$    |
|                            $t u(t)$                             |                 $\dfrac{1}{s^2}$                  |    $\sigma > 0$    |
|                          $t^{k} u(t)$                           |               $\dfrac{k!}{s^{k+1}}$               |    $\sigma > 0$    |
| $u\left(t + \frac{T}{2}\right) - u\left(t - \frac{T}{2}\right)$ | $\dfrac{e^{\frac{sT}{2}} - e^{-\frac{sT}{2}}}{s}$ | $\sigma > -\infty$ |
|                         $e^{-a t} u(t)$                         |                $\dfrac{1}{s + a}$                 |   $\sigma > -a$    |
|                    $e^{-a \lvert t \rvert}$                     |              $\dfrac{2a}{a^2 - s^2}$              |         $          | \sigma | < a$ |
|                      $t^{k} e^{-a t} u(t)$                      |            $\dfrac{k!}{(s + a)^{k+1}}$            |   $\sigma > -a$    |
|                     $\sin(\omega_0 t) u(t)$                     |       $\dfrac{\omega_0}{s^2 + \omega_0^2}$        |    $\sigma > 0$    |
|                     $\cos(\omega_0 t) u(t)$                     |           $\dfrac{s}{s^2 + \omega_0^2}$           |    $\sigma > 0$    |
|                $e^{-a t} \sin(\omega_0 t) u(t)$                 |    $\dfrac{\omega_0}{(s + a)^2 + \omega_0^2}$     |   $\sigma > -a$    |
|                $e^{-a t} \cos(\omega_0 t) u(t)$                 |      $\dfrac{s + a}{(s + a)^2 + \omega_0^2}$      |   $\sigma > -a$    |
