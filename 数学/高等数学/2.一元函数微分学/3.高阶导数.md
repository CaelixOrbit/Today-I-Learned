# 高阶导数

## 高阶导数的概念

**定义**：如果函数 $y = f(x)$ 的导函数 $f'(x)$ 在点 $x$ 处可导，就称 $y = f(x)$ 在点 $x$ 处**二阶可导**。$f'(x)$ 在点 $x$ 处的导数称为函数 $y = f(x)$ 在点 $x$ 处的**二阶导数**，记作 $f''(x)$，$y''$，$\dfrac{\mathrm{d}^2 y}{\mathrm{d} x^2}$ 或 $\dfrac{\mathrm{d}^2 f(x)}{\mathrm{d} x^2}$，即：

$$
f''(x) = [f'(x)]' \quad \text{或} \quad \frac{\mathrm{d}^2 y}{\mathrm{d} x^2} = \frac{\mathrm{d}}{\mathrm{d} x} \left( \frac{\mathrm{d} y}{\mathrm{d} x} \right)
$$

用极限来表示即为：

$$
f''(x) = \lim_{\Delta x \to 0} \frac{f'(x + \Delta x) - f'(x)}{\Delta x}
$$

一般地，$f(x)$ 的 $n-1$ 阶导数的导数（如果存在的话）称为 $f(x)$ 的 **$n$ 阶导数**，$n$ 阶导数记作 $f^{(n)}(x)$，$y^{(n)}$，$\dfrac{\mathrm{d}^n y}{\mathrm{d} x^n}$ 或 $\dfrac{\mathrm{d}^n f(x)}{\mathrm{d} x^n}$，即：

$$
f^{(n)}(x) = [f^{(n-1)}(x)]' \quad \text{或} \quad \frac{\mathrm{d}^n y}{\mathrm{d} x^n} = \frac{\mathrm{d}}{\mathrm{d} x} \left( \frac{\mathrm{d}^{n-1} y}{\mathrm{d} x^{n-1}} \right)
$$

二阶及二阶以上的导数称为**高阶导数**，$f'(x)$ 称为**一阶导数**，有时为了方便也将 $f(x)$ 称为**零阶导数**，即 $f^{(0)} = f(x)$。

**注**：$n-1$ 阶可导不一定说明 $n$ 阶可导。

**常见高阶导数的公式**：

- $\left( a^x \right)^{(n)} = (\ln a)^n a^x$

- $\left( e^{\lambda x} \right)^{(n)} = \lambda^n e^{\lambda x}$

- $\left( \sin x \right)^{(n)} = \sin \left( x + n \cdot \dfrac{\pi}{2} \right)$

- $\left( \cos x \right)^{(n)} = \cos \left( x + n \cdot \dfrac{\pi}{2} \right)$

- $\left( \sin \omega x \right)^{(n)} = \omega^n \sin \left( \omega x + n \cdot \dfrac{\pi}{2} \right)$

- $\left( \cos \omega x \right)^{(n)} = \omega^n \cos \left( \omega x + n \cdot \dfrac{\pi}{2} \right)$

- $\left[ (x + C)^\mu \right]^{(n)} = \mu (\mu - 1) \cdots (\mu - n + 1) (x + C)^{\mu - n}$

- $\left( \dfrac{1}{x + C} \right)^{(n)} = \dfrac{(-1)^{n} (n)!}{(x + C)^{n+1}}$

- $\left[ \ln(x + C) \right]^{(n)} = \left\{ \left[ \ln(x + C) \right]' \right\}^{(n-1)} = \dfrac{(-1)^{n-1} (n-1)!}{(x + C)^n}$

## 高阶导数的运算法则

设函数 $u = u(x)$ 及 $v = v(x)$ 都有 $n$ 阶导数，则：

- $(u \pm v)^{(n)} = u^{(n)} \pm v^{(n)}$；

- $(Cu)^{(n)} = C u^{(n)}$（其中 $C$ 为常数）；

- $(uv)^{(n)} = \sum\limits_{k=0}^{n} C_n^k u^{(n-k)} v^{(k)}$。

## 反函数的二阶导数

设 $y = f(x)$ 有反函数 $x = \varphi(y)$，且 $f(x)$，$\varphi(y)$ 分别二阶可导，$\varphi'(y) \ne 0$，则 $f''(x) = -\dfrac{\varphi''(y)}{[\varphi'(y)]^3}$。
