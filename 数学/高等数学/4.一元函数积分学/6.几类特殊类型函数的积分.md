# 几类特殊类型函数的积分

## 有理函数的积分

有理函数是指两个多项式函数的商，记为 $\dfrac{P_m(x)}{Q_n(x)}$，其中 $P_m(x)$，$Q_n(x)$ 分别为 $m$ 次，$n$ 次实多项式，即：

$$
\frac{P_m(x)}{Q_n(x)} = \frac{a_0 + a_1 x + \cdots + a_m x^m}{b_0 + b_1 x + \cdots + b_n x^n}
$$

其中 $m$，$n$ 是非负整数，$a_0, a_1, \dots, a_m$ 及 $b_0, b_1, \dots, b_n$ 均为实数，且 $a_m \ne 0$，$b_n \ne 0$。

**基本思想**：通过分解技术将有理函数的积分转化为积分表中函数的积分或者已知函数的不定积分来处理。

对于有理函数 $\dfrac{P_m(x)}{Q_n(x)}$，总假定分子 $P_m(x)$ 与分母 $Q_n(x)$ 没有公因式，且当 $m < n$ 时，称之为**真分式**，当 $m \geqslant n$ 时，称之为**假分式**。

如果 $\dfrac{P_m(x)}{Q_n(x)}$ 为假分式，则利用多项式的除法，可将 $\dfrac{P_m(x)}{Q_n(x)}$ 转化为多项式与真分式之和。

设 $\dfrac{P_m(x)}{Q_n(x)}$ 为真分式，求 $\int \dfrac{P_m(x)}{Q_n(x)} \, \mathrm{d}x$ 的方法是将其分解为若干个简单分式的积分进行计算。

具体步骤为：

1. 将分母 $Q_n(x)$ 在实数范围内因式分解，理论上，$Q_n(x)$ 总可以分解为若干个一次因式与二次不可约因式的乘积。

2. 把真分式 $\dfrac{P_m(x)}{Q_n(x)}$ 表示成一些简单分式的和。具体做法为：

   1. 如果 $Q_n(x)$ 因式分解式中含有因子 $(x - a)^k$，则 $\dfrac{P_m(x)}{Q_n(x)}$ 中对应地含有下列 $k$ 个简单分式之和：

      $$
      \frac{A_1}{x - a} + \frac{A_2}{(x - a)^2} + \cdots + \frac{A_k}{(x - a)^k}
      $$

      其中 $A_1, A_2, \dots, A_k$ 为待定系数。

   2. 如果 $Q_n(x)$ 因式分解式中含有因子 $(x^2 + px + q)^l$，其中 $p^2 - 4q < 0$，则 $\dfrac{P_m(x)}{Q_n(x)}$ 中对应地含有下列 $l$ 个简单分式之和：

      $$
      \frac{M_1 x + N_1}{x^2 + px + q} + \frac{M_2 x + N_2}{(x^2 + px + q)^2} + \cdots + \frac{M_l x + N_l}{(x^2 + px + q)^l}
      $$

      其中 $M_i$，$N_i$（$i = 1,2,\dots,l$）为待定系数。

3. 利用待定系数法等方法，确定以上所有待定系数 $A_1, A_2, \dots, A_k$ 以及 $M_i, N_i$（$i = 1,2,\dots,l$）等的值。

4. 根据 $\dfrac{P_m(x)}{Q_n(x)}$ 的简单分式之和，将 $\int \dfrac{P_m(x)}{Q_n(x)} \, \mathrm{d}x$ 的计算归结为下列四种不定积分的计算：

   - $\int \dfrac{1}{x - a} \, \mathrm{d}x = \ln|x - a| + C$；

   - $\int \dfrac{1}{(x - a)^k} \, \mathrm{d}x = \dfrac{1}{1-k}(x - a)^{1-k} + C$（正整数 $k>1$）；

   - 设 $p^2-4q<0$，令 $a = \sqrt{q - \dfrac{p^2}{4}}$，$b = N - \dfrac{Mp}{2}$，则：

     - $\int \dfrac{Mx + N}{x^2 + px + q} \, \mathrm{d}x = \dfrac{M}{2} \ln(x^2 + px + q) + \dfrac{b}{a} \arctan \dfrac{x + \dfrac{p}{2}}{a} + C$；

     - $\int \dfrac{Mx + N}{(x^2 + px + q)^l} \, \mathrm{d}x = \dfrac{2bx + bp - 2Ma^2}{4(l-1)a^2 (x^2 + px + q)^{l-1}} + \dfrac{b(2l-3)}{2(l-1)a^2} \int \dfrac{1}{(x^2 + px + q)^{l-1}} \, \mathrm{d}x$（正整数 $l>1$）。

## 三角函数有理式的积分

三角函数有理式是指由 $\sin x$，$\cos x$ 和常数经过有限次四则运算而得到的函数，记为 $R(\sin x, \cos x)$。

对于三角有理式的积分 $\int R(\sin x, \cos x) \, \mathrm{d}x$，通常有两种方法计算：

- 利用三角函数关系式变形后计算；

- 利用换元法转化为有理函数积分。

**万能换元法**：在三角函数有理式的积分中，令 $u = \tan \dfrac{x}{2}$，或 $x = 2 \arctan u$，则：

$$
\sin x = \frac{2u}{1 + u^2}, \quad \cos x = \frac{1 - u^2}{1 + u^2}, \quad \mathrm{d}x = \frac{2}{1 + u^2} \, \mathrm{d}u
$$

所以得：

$$
\int R(\sin x, \cos x) \, \mathrm{d}x = \int R\left( \frac{2u}{1 + u^2}, \frac{1 - u^2}{1 + u^2} \right) \cdot \frac{2}{1 + u^2} \, \mathrm{d}u
$$

右端积分为有理函数的积分。由于有理函数的不定积分均可求出，因此三角函数的有理积分也可求出，并且三角函数有理式的原函数也是初等函数。

**注**：但是在很多情况下，采用万能换元法所得到的积分较繁杂，因此不把万能换元法作为三角函数有理式积分的首选方法。

## 简单无理式的积分

- $\int \dfrac{1}{\sqrt{1 - x^2}} \, \mathrm{d}x = \arcsin x + C$；

- $\int \dfrac{\mathrm{d}x}{\sqrt{x^2 + a^2}} = \ln(x + \sqrt{x^2 + a^2}) + C$；

- $\int \dfrac{x}{\sqrt{1 + x^2}} \, \mathrm{d}x = \int \dfrac{1}{2\sqrt{1 + x^2}} \, \mathrm{d}(1 + x^2) = \sqrt{1 + x^2} + C$；

- $\int \dfrac{1}{\sqrt{x} \sqrt{1 - x}} \, \mathrm{d}x = 2 \int \dfrac{1}{\sqrt{1 - (\sqrt{x})^2}} \, \mathrm{d}\sqrt{x} = 2 \arcsin \sqrt{x} + C$。

对于不定积分 $\int R\left( x, \sqrt[n]{\dfrac{ax + b}{cx + d}} \right) \, \mathrm{d}x$，其中 $R(x,u)$ 表示 $x$，$u$ 的有理式，且 $ad - bc \ne 0$，通常令 $u = \sqrt[n]{\dfrac{ax + b}{cx + d}}$，则：

$$
x = \frac{b - d u^n}{c u^n - a}, \quad \mathrm{d}x = \frac{n(ad - bc) u^{n-1}}{(c u^n - a)^2} \, \mathrm{d}u
$$

故有：

$$
\int R\left( x, \sqrt[n]{\frac{ax + b}{cx + d}} \right) \, \mathrm{d}x = \int R\left( \frac{b - d u^n}{c u^n - a}, u \right) \frac{n(ad - bc) u^{n-1}}{(c u^n - a)^2} \, \mathrm{d}u
$$

为有理函数的积分，可利用有理函数积分的方法求解。
