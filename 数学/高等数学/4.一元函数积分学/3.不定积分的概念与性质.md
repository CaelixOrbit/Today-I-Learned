# 不定积分的概念与性质

## 不定积分的概念

**定义**：如果函数 $f(x)$ 在区间 $I$ 上（内）存在原函数 $F(x)$，则称 $f(x)$ 在区间 $I$ 上（内）的全体原函数为 $f(x)$ 在区间 $I$ 上（内）的**不定积分**，记为 $\int f(x) \, \mathrm{d}x$，即：

$$
\int f(x) \, \mathrm{d}x = F(x) + C
$$

不定积分运算与微分运算（或求导运算）构成了一对 "准" 逆运算：

- $\mathrm{d} \int f(x) \, \mathrm{d}x = f(x) \, \mathrm{d}x$；

- $\left( \int f(x) \, \mathrm{d}x \right)' = f(x)$；

- $\int \mathrm{d} F(x) = F(x) + C$；

- $\int F'(x) \, \mathrm{d}x = F(x) + C$。

## 基本积分表

- $\int 0 \, \mathrm{d}x = C$；

- $\int k \, \mathrm{d}x = kx + C$（$k$ 为常数）；

- $\int x^\mu \, \mathrm{d}x = \dfrac{1}{\mu + 1} x^{\mu + 1} + C$（$\mu \ne -1$）；

- $\int \dfrac{1}{x} \, \mathrm{d}x = \ln |x| + C$；

- $\int \dfrac{1}{1 + x^2} \, \mathrm{d}x = \arctan x + C \, ( = -\operatorname{arccot} x + C)$；

- $\int \dfrac{1}{\sqrt{1 - x^2}} \, \mathrm{d}x = \arcsin x + C \, ( = -\arccos x + C)$；

- $\int \cos x \, \mathrm{d}x = \sin x + C$；

- $\int \sin x \, \mathrm{d}x = -\cos x + C$；

- $\int e^x \, \mathrm{d}x = e^x + C$；

- $\int a^x \, \mathrm{d}x = \dfrac{a^x}{\ln a} + C$。

## 不定积分的性质

**线性**：设 $k_1$，$k_2$ 为常数，$f(x)$，$g(x)$ 可积，则：

$$
\int [k_1 f(x) + k_2 g(x)] \, \mathrm{d}x = k_1 \int f(x) \, \mathrm{d}x + k_2 \int g(x) \, \mathrm{d}x
$$

该性质可推广到有限个函数的线性组合。
