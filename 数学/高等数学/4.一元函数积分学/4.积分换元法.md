# 换元积分法

## 不定积分换元法

### 第一类换元法

**定理**：设函数 $f(u)$ 在区间 $D$ 上（内）有一个原函数 $F(u)$，$u = \varphi(x)$ 在区间 $I$ 上（内）可导，且有 $\{\varphi(x) \mid x \in I\} \subset D$，则：

$$
\int f[\varphi(x)] \varphi'(x) \, \mathrm{d}x = \int f(u) \, \mathrm{d}u = F(u) + C = F[\varphi(x)] + C
$$

**基本积分表（复合）**：

- $\int k \, \mathrm{d}\blacksquare = k \blacksquare + C$；

- $\int \blacksquare^\mu \, \mathrm{d}\blacksquare = \dfrac{1}{\mu + 1} \blacksquare^{\mu + 1} + C \quad (\mu \ne -1)$；

- $\int \dfrac{1}{\blacksquare} \, \mathrm{d}\blacksquare = \ln|\blacksquare| + C$；

- $\int \dfrac{1}{1 + \blacksquare^2} \, \mathrm{d}\blacksquare = \arctan \blacksquare + C \, ( = -\operatorname{arccot} \blacksquare + C)$；

- $\int \dfrac{1}{\sqrt{1 - \blacksquare^2}} \, \mathrm{d}\blacksquare = \arcsin \blacksquare + C \, ( = -\arccos \blacksquare + C)$；

- $\int \cos \blacksquare \, \mathrm{d}\blacksquare = \sin \blacksquare + C$；

- $\int \sin \blacksquare \, \mathrm{d}\blacksquare = -\cos \blacksquare + C$；

- $\int e^{\blacksquare} \, \mathrm{d}\blacksquare = e^{\blacksquare} + C$；

- $\int a^{\blacksquare} \, \mathrm{d}\blacksquare = \dfrac{a^{\blacksquare}}{\ln a} + C$。

**常见的几种配元形式**：

- $\int f(ax + b) \, \mathrm{d}x = \dfrac{1}{a} \int f(ax + b) \, \mathrm{d}(ax + b)$；

- $\int f(x^n) x^{n-1} \, \mathrm{d}x = \dfrac{1}{n} \int f(x^n) \, \mathrm{d}x^n$；

- $\int f(x^n) \dfrac{1}{x} \, \mathrm{d}x = \dfrac{1}{n} \int f(x^n) \dfrac{1}{x^n} \, \mathrm{d}x^n$；

- $\int f(\sin x) \cos x \, \mathrm{d}x = \int f(\sin x) \, \mathrm{d}\sin x$；

- $\int f(\cos x) \sin x \, \mathrm{d}x = -\int f(\cos x) \, \mathrm{d}\cos x$；

- $\int f(e^x) e^x \, \mathrm{d}x = \int f(e^x) \, \mathrm{d}e^x$；

- $\int f(\ln x) \dfrac{1}{x} \, \mathrm{d}x = \int f(\ln x) \, \mathrm{d}\ln x$。

### 第二类换元法

**定理**：设函数 $f(x)$ 在区间 $I$ 上（内）连续，$x = \psi(t)$ 在 $I$ 的对应区间 $I_t$ 上（内）单调，并有连续导数，且 $\psi'(t) \ne 0$，$f[\psi(t)] \psi'(t)$ 具有原函数 $G(t)$，则有换元公式：

$$
\int f(x) \, \mathrm{d}x = \int f[\psi(t)] \psi'(t) \, \mathrm{d}t = G(t) + C = G(\psi^{-1}(x)) + C
$$

其中 $t = \psi^{-1}(x)$ 是 $x = \psi(t)$ 的反函数，$I_t = \{t \mid t = \psi^{-1}(x), x \in I\}$。

为了化掉根式可以用三角函数代换，但不一定必须要用三角函数代换。

当分母的阶较高时，可采用倒代换，即 $x = \dfrac{1}{t}$。

## 定积分换元法

**定理**：设函数 $f(x)$ 在 $[a,b]$ 上连续，函数 $x = \varphi(t)$ 为单值函数，且满足：

- $\varphi(\alpha) = a$，$\varphi(\beta) = b$，且当 $t \in [\alpha,\beta]$ 或 $[\beta,\alpha]$ 时，$\varphi(t) \in [a,b]$；

- $\varphi(t)$ 在 $[\alpha,\beta]$ 上具有连续导数。

则有：

$$
\int_a^b f(x) \, \mathrm{d}x = \int_\alpha^\beta f[\varphi(t)] \varphi'(t) \, \mathrm{d}t
$$

**定积分换元法与不定积分换元法的不同点**：

- 在定积分换元法中，积分上限和积分下限需要变换，并且变换前后的积分上限和积分下限相互对应，而不定积分换元法中无此项。

- 不定积分换元法中，换元后的新变量要换回原来变量，而定积分换元法不需要换回，只需继续计算，直到算出定积分为止。

- 不定积分有第一换元法和第二换元法，而定积分仅此一个换元法。

**常见的积分等式**：

- $\int_a^b f(x) \, \mathrm{d}x = \int_a^b f(a + b - x) \, \mathrm{d}x$（证明提示：令 $x = a + b - t$）；

- $\int_0^\pi f(\sin x) \, \mathrm{d}x = 2\int_0^{\pi / 2} f(\cos x) \, \mathrm{d}x$（证明提示：令 $x = \dfrac{\pi}{2} - t$）；

- $\int_0^\pi x f(\sin x) \, \mathrm{d}x = \dfrac{\pi}{2} \int_0^\pi f(\sin x) \, \mathrm{d}x$（证明提示：令 $x = \pi - t$）。

## 奇偶函数定积分的性质

**定理**：设 $f(x)$ 为连续函数，则：

- 如果 $f(x)$ 为奇函数，则 $\int_0^x f(t) \, \mathrm{d}t$ 为偶函数；

- 如果 $f(x)$ 为偶函数，则 $\int_0^x f(t) \, \mathrm{d}t$ 为奇函数。

**定理**：设函数 $f(x)$ 在 $[-a,a] \, (a > 0)$ 上连续，则：

$$
\int_{-a}^a f(x) \, \mathrm{d}x = \int_0^a [f(-x) + f(x)] \, \mathrm{d}x
$$

因此：

$$
\int_{-a}^a f(x) \, \mathrm{d}x = \begin{cases}
0, & f(x) \text{ 为奇函数} \\[2ex]
2 \int_0^a f(x) \, \mathrm{d}x, & f(x) \text{ 为偶函数}
\end{cases}
$$

## 周期函数定积分的性质

**定理**：设 $f(x)$ 是以 $T \, (T > 0)$ 为周期的连续函数，则：

- 对任意的常数 $a$，有 $\int_a^{a+T} f(x) \, \mathrm{d}x = \int_0^T f(x) \, \mathrm{d}x$；

- 对任意的正整数 $n$，有 $\int_a^{a+nT} f(x) \, \mathrm{d}x = n \int_0^T f(x) \, \mathrm{d}x$。
