# 空间直线

## 空间直线方程

### 一般方程

空间直线可视为两个相交平面的交线，因此**一般方程**为：

$$
\begin{cases}
A_1 x + B_1 y + C_1 z + D_1 = 0 \\
A_2 x + B_2 y + C_2 z + D_2 = 0
\end{cases}
$$

### 对称式方程

**定义**：称平行于空间直线 $L$ 的非零向量 $\vec{s}$ 为直线 $L$ 的**方向向量**。

设空间直线 $L$ 经过已知点 $M_0(x_0, y_0, z_0)$，且方向向量为 $\vec{s} = \{m, n, p\}$，则点 $M(x,y,z)$ 在直线 $L$ 上的充要条件是 $\overrightarrow{M_0M} \parallel \vec{s}$，故有：

$$
\frac{x - x_0}{m} = \frac{y - y_0}{n} = \frac{z - z_0}{p}
$$

上式称为直线 $L$ 的**对称式方程**（或**点向式方程**）。

**注**：当某些分母为零时，其分子也理解为零。例如：当 $m = n = 0$，$p \ne 0$ 时，直线方程为 $\begin{cases} x = x_0 \\ y = y_0 \end{cases}$。

### 参数式方程

设 $\dfrac{x - x_0}{m} = \dfrac{y - y_0}{n} = \dfrac{z - z_0}{p} = t$，得**参数式方程**：

$$
\begin{cases}
x = x_0 + m t \\
y = y_0 + n t \\
z = z_0 + p t
\end{cases}
$$

## 两直线的夹角

**定义**：两直线的方向向量的夹角（规定不取钝角），称为**两直线的夹角**。

设直线 $L_1$，$L_2$ 的方向向量分别为 $\vec{s}_1 = \{m_1, n_1, p_1\}$，$\vec{s}_2 = \{m_2, n_2, p_2\}$，则两直线夹角 $\varphi$ 满足：

$$
\cos \varphi = \frac{|\vec{s}_1 \cdot \vec{s}_2|}{|\vec{s}_1|\,|\vec{s}_2|} = \frac{|m_1 m_2 + n_1 n_2 + p_1 p_2|}{\sqrt{m_1^2 + n_1^2 + p_1^2}\ \sqrt{m_2^2 + n_2^2 + p_2^2}}
$$

特别有：

- $L_1 \perp L_2 \ \Leftrightarrow\ \vec{s}_1 \perp \vec{s}_2 \ \Leftrightarrow\ m_1 m_2 + n_1 n_2 + p_1 p_2 = 0$；

- $L_1 \parallel L_2 \ \Leftrightarrow\ \vec{s}_1 \parallel \vec{s}_2 \ \Leftrightarrow\ \dfrac{m_1}{m_2} = \dfrac{n_1}{n_2} = \dfrac{p_1}{p_2}$。

## 直线与平面的夹角

**定义**：过直线 $L$ 且与平面 $\pi$ 垂直的平面与平面 $\pi$ 的交线称为直线 $L$ 在平面 $\pi$ 上的**投影直线**（简称**投影**）。如果直线 $L$ 的方向向量与平面 $\pi$ 的法向量平行，规定直线在平面上的投影为一点（垂足），这时也称**直线与平面垂直**。

**定义**：直线与它在平面上的投影直线的夹角（规定不取钝角，当直线与平面垂直时，规定它们的夹角为 $\dfrac{\pi}{2}$），称为**直线与平面的夹角**。

设直线 $L$ 的方向向量为 $\vec{s} = \{m, n, p\}$，平面 $\pi$ 的法向量为 $\vec{n} = \{A, B, C\}$，则直线与平面夹角 $\varphi$ 满足：

$$
\sin \varphi = |\cos(\widehat{\vec{s}, \vec{n}})| = \frac{|\vec{s} \cdot \vec{n}|}{|\vec{s}|\,|\vec{n}|} = \frac{|A m + B n + C p|}{\sqrt{m^2 + n^2 + p^2}\ \sqrt{A^2 + B^2 + C^2}}
$$

特别有：

- $L \perp \pi \ \Leftrightarrow\ \vec{s} \parallel \vec{n} \ \Leftrightarrow\ \dfrac{A}{m} = \dfrac{B}{n} = \dfrac{C}{p}$；

- $L \parallel \pi \ \Leftrightarrow\ \vec{s} \perp \vec{n} \ \Leftrightarrow\ A m + B n + C p = 0$。

## 平面束方程

**定义**：过直线 $L$ 的平面的全体称为直线 $L$ 的**平面束**。

设直线 $L$ 的一般方程为：

$$
\begin{cases} A_1 x + B_1 y + C_1 z + D_1 = 0 \\ A_2 x + B_2 y + C_2 z + D_2 = 0 \end{cases}
$$

其中 $A_1$，$B_1$，$C_1$ 和 $A_2$，$B_2$，$C_2$ 不成比例，则其平面束方程为：

$$
\lambda_1 (A_1 x + B_1 y + C_1 z + D_1) + \lambda_2 (A_2 x + B_2 y + C_2 z + D_2) = 0
$$

其中 $\lambda_1$ 与 $\lambda_2$ 不全为零。
