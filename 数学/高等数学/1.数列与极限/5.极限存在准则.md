# 极限存在准则

## 夹逼准则

- **对数列**：假设三个数列 $\{x_n\}$，$\{y_n\}$，$\{z_n\}$ 满足下列两个条件：

  - 存在 $N \in \mathbb{N}$，当 $n > N$ 时，有 $y_n \leqslant x_n \leqslant z_n$；

  - $\lim\limits_{n \to \infty} y_n = \lim\limits_{n \to \infty} z_n = a$；

  则数列 $\{x_n\}$ 收敛，且 $\lim\limits_{n \to \infty} x_n = a$。

- **对函数**：设在自变量的同一变化过程中，$g(x)$，$f(x)$，$h(x)$ 都有定义，且满足：

  - $g(x) \leqslant f(x) \leqslant h(x)$；

  - $\lim g(x) = \lim h(x) = A$；

  则 $\lim f(x) = A$。

**注**：

- 夹逼准则中 $a$ 或 $A$ 如果换成 $+\infty$（或 $-\infty$），结论仍成立。

- 利用夹逼准则求极限，关键要对数列（函数）进行适当的放缩。

## 单调有界收敛准则

- **对数列**：单调有界数列一定收敛。即如果单调递增（或单调递减）数列 $\{x_n\}$ 有上界（或下界），即存在常数 $M$，使得 $x_n \leqslant M$（或 $x_n \geqslant M$），$n = 1, 2, \dots$，则 $\lim\limits_{n \to \infty} x_n$ 存在，且 $\lim\limits_{n \to \infty} x_n \leqslant M$（或 $\lim\limits_{n \to \infty} x_n \geqslant M$）。

- **对函数**：若函数 $f(x)$ 在 $[a, +\infty)$ 上单调递增（或单调递减），且存在常数 $M$，使得当 $x > a$ 时有 $f(x) \leqslant M$（或 $f(x) \geqslant M$），则 $\lim\limits_{x \to +\infty} f(x)$ 存在；若函数 $f(x)$ 在 $(-\infty, a]$ 上单调递增（或单调递减），且存在常数 $M$，使得当 $x < a$ 时有 $f(x) \geqslant M$（或 $f(x) \leqslant M$），则 $\lim\limits_{x \to -\infty} f(x)$ 存在。

  **注**：对有限点处的双侧极限，单调有界未必能保证极限存在。例如

  $$
  f(x) =
  \begin{cases}
      x - 1, & -1 \leqslant x < 0, \\
      0,     & x = 0, \\
      x + 1, & 0 < x \leqslant 1
  \end{cases}
  $$

  该函数单调递增且有上界，但 $\lim\limits_{x \to 0} f(x)$ 不存在。

## 重要极限

- $\lim\limits_{n \to \infty} \left(1 + \dfrac{1}{n}\right)^n = e$，$\lim\limits_{x \to \infty} \left(1 + \dfrac{1}{x}\right)^x = e$，$\lim\limits_{x \to 0} \left(1 + x\right)^{1/x} = e$

- $\lim\limits_{\blacksquare \to \infty} \left(1 + \dfrac{1}{\blacksquare}\right)^\blacksquare = e$，$\lim\limits_{\blacksquare \to 0} \left(1 + \blacksquare\right)^{1/\blacksquare} = e$
