# 二阶线性微分方程的理论及其解法

**定义**：形如：

$$
y^{(n)} + p_{n-1}(x) y^{(n-1)} + \cdots + p_1(x) y' + p_0(x) y = f(x)
$$

的微分方程称为 **$n$ 阶线性微分方程**，其中 $p_0(x), p_1(x), \cdots, p_{n-1}(x), f(x)$ 都是 $x$ 的函数。

- 当 $f(x) \not\equiv 0$ 时，称为 **$n$ 阶非齐次线性微分方程**；

- 当 $f(x) \equiv 0$ 时，称为 **$n$ 阶齐次线性微分方程**，也称为对应于非齐次方程的齐次方程。

## 函数组的线性相关性

**定义**：设 $y_1(x), y_2(x), \dots, y_n(x)$ 为定义在区间 $I$ 上的 $n$ 个函数，若存在不全为 $0$ 的 $n$ 个常数 $k_1, k_2, \dots, k_n$，使得在区间 $I$ 上恒有：

$$
k_1 y_1(x) + k_2 y_2(x) + \cdots + k_n y_n(x) \equiv 0
$$

则称这 $n$ 个函数在区间 $I$ 上**线性相关**，否则称为**线性无关**。

**注**：$0$ 与任意函数必线性相关。

两个函数线性相关的充要条件：

- $y_1(x)$，$y_2(x)$ 线性相关 $\Leftrightarrow k_1 y_1(x) + k_2 y_2(x) \equiv 0 \Leftrightarrow y_1(x) \equiv k \cdot y_2(x)$。

  即 $y_1(x)$，$y_2(x)$ 仅相差常数倍。

- $y_1(x)$，$y_2(x)$ 线性无关 $\Leftrightarrow \dfrac{y_1(x)}{y_2(x)} \not\equiv$ 常数。

## 二阶齐次线性微分方程解的性质与结构

**定理（解的叠加原理）**：如果函数 $y_1(x)$，$y_2(x)$ 是二阶线性齐次方程 $y'' + P(x) y' + Q(x) y = 0$ 的两个解，则：

$$
y = C_1 y_1(x) + C_2 y_2(x)
$$

也是该方程的解，其中 $C_1$，$C_2$ 为任意常数。

**注**：$y = C_1 y_1(x) + C_2 y_2(x)$ 未必是方程的通解，因为 $y_1$ 与 $y_2$ 未必线性无关。

**定理**：如果函数 $y_1(x)$，$y_2(x)$ 是二阶齐次线性微分方程的两个线性无关特解，则该方程的通解为：

$$
y = C_1 y_1(x) + C_2 y_2(x)
$$

其中 $C_1$，$C_2$ 为任意常数。

**推论**：如果函数 $y_1, y_2, \dots, y_n$ 是 $n$ 阶线性齐次微分方程的 $n$ 个线性无关解，则该方程的通解为：

$$
y = C_1 y_1 + \cdots + C_n y_n
$$

其中 $C_i$（$i = 1, 2, \cdots, n$）为任意常数。

## 二阶非齐次线性微分方程解的性质与结构

**定理**：设 $y^*(x)$ 是二阶非齐次线性微分方程 $y'' + P(x) y' + Q(x) y = f(x)$ 的一个特解，$Y(x)$ 是对应齐次方程 $y'' + P(x) y' + Q(x) y = 0$ 的通解，则：

$$
y = \underbrace{Y(x)}_{\text{齐次方程通解}} + \underbrace{y^*(x)}_{\text{非齐次方程特解}}
$$

是二阶非齐次线性微分方程的通解。

**推广**：给定 $n$ 阶非齐次线性微分方程，设 $y_1, y_2, \dots, y_n$ 是对应齐次方程的 $n$ 个线性无关特解，$y^*(x)$ 是非齐次方程的特解，则非齐次方程的通解为：

$$
y = C_1 y_1(x) + C_2 y_2(x) + \cdots + C_n y_n(x) + y^*(x) = Y(x) + y^*(x)
$$

其中 $C_i$（$i = 1, 2, \cdots, n$）为任意常数。

**定理**：设函数 $y_1(x)$，$y_2(x)$ 分别是二阶非齐次线性微分方程 $y'' + P(x) y' + Q(x) y = f(x)$ 和对应齐次方程的特解，则：

$$
y = y_1(x) + y_2(x)
$$

是二阶非齐次线性微分方程 $y'' + P(x) y' + Q(x) y = f(x)$ 的一个特解。

**定理**：设函数 $y_1(x)$，$y_2(x)$ 是二阶非齐次线性微分方程 $y'' + P(x) y' + Q(x) y = f(x)$ 的两个特解，则：

$$
y_1(x) - y_2(x)
$$

是对应齐次方程的一个特解。

**定理（解的叠加原理）**：设函数 $y_i^*(x)$（$i = 1, 2, \dots, n$）分别是方程：

$$
y'' + P(x) y' + Q(x) y = f_i(x)
$$

的特解，则方程：

$$
y'' + P(x) y' + Q(x) y = \sum\limits_{i=1}^{n} k_i f_i(x)
$$

的特解为：

$$
y = \sum\limits_{i=1}^{n} k_i y_i^*
$$

其中 $k_i$（$i = 1, 2, \dots, n$）为任意常数（也可以是复数）。

## 二阶常系数齐次线性微分方程的解法

**定义**：如果 $n$ 阶线性微分方程的系数都是常数，即：

$$
y^{(n)} + p_{n-1} y^{(n-1)} + \cdots + p_1 y' + p_0 y = f(x)
$$

其中 $p_{n-1}, \cdots, p_1, p_0$ 均为常数，称其为 **$n$ 阶常系数线性微分方程**。

- 如果 $f(x) \equiv 0$，称为 $n$ 阶常系数齐次线性微分方程；

- 如果 $f(x) \not\equiv 0$，称为 $n$ 阶常系数非齐次线性微分方程。

求二阶常系数齐次线性微分方程：

$$
y'' + p y' + q y = 0
$$

其通解的步骤为：

1. 写出微分方程的特征方程 $r^2 + p r + q = 0$；

2. 求出特征方程的根 $r_1$，$r_2$；

3. 根据 $r_1$，$r_2$ 的不同情况，按照下表写出微分方程的通解。

| 特征方程 $r^2 + p r + q = 0$ 的根                    | 微分方程 $y'' + p y' + q y = 0$ 的通解                   |
| :--------------------------------------------------- | :------------------------------------------------------- |
| 两个不相等的实根 $r_1$，$r_2$                          | $y = C_1 e^{r_1 x} + C_2 e^{r_2 x}$                      |
| 两个相等的实根 $r_1 = r_2 = r$                       | $y = (C_1 + C_2 x) e^{r x}$                              |
| 一对共轭复根 $r_{1,2} = \alpha \pm \beta \mathrm{i}$ | $y = e^{\alpha x} (C_1 \cos \beta x + C_2 \sin \beta x)$ |

**推广**：$n$ 阶常系数齐次微分方程为：

$$
y^{(n)} + a_1 y^{(n-1)} + \cdots + a_{n-1} y' + a_n y = 0
$$

其中 $a_k$ 均为常数，其特征方程为 $r^n + a_1 r^{n-1} + \cdots + a_{n-1} r + a_n = 0$。

- 若含 $k$ 重实根 $r$，则其通解中必含 $k$ 项：

  $$
  (C_1 + C_2 x + \cdots + C_k x^{k-1}) e^{r x}
  $$

  其中 $C_i$ 为任意常数。

- 若含一对 $k$ 重共轭复根 $r = \alpha \pm \beta\mathrm{i}$，则其通解中必含 $2k$ 项：

  $$
  e^{\alpha x} \left[ (C_1 + C_2 x + \cdots + C_k x^{k-1}) \cos \beta x + (D_1 + D_2 x + \cdots + D_k x^{k-1}) \sin \beta x \right]
  $$

  其中 $C_i$，$D_i$ 均为任意常数。

## 二阶常系数非齐次线性微分方程的解法

设二阶常系数非齐次线性微分方程为：

$$
y'' + p y' + q y = f(x)
$$

其中 $p$，$q$ 为常数。

- 当 $f(x) = e^{\lambda x} P_m(x)$（$\lambda$ 为常数，$P_m(x)$ 为 $m$ 次多项式）时，有特解：

  $$
  y^* = x^k e^{\lambda x} Q_m(x)
  $$

  其中 $Q_m(x)$ 是 $m$ 次待定多项式，$k$ 按 $\lambda$ 不是特征方程的根，是特征方程的单根，重根依次取 $0$，$1$，$2$。

- 当 $f(x) = e^{\lambda x} \left[ P_l(x) \cos \omega x + \tilde{P}_n(x) \sin \omega x \right]$ （$\lambda$，$\omega$ 为常数，$P_l(x)$，$\tilde{P}_n(x)$ 分别为 $l$ 次，$n$ 次多项式）时，有特解：

  $$
  y^* = x^k e^{\lambda x} \left[ R_m(x) \cos \omega x + \tilde{R}_m(x) \sin \omega x \right]
  $$

  其中 $m = \max\{n, l\}$，$R_m(x)$，$\tilde{R}_m(x)$ 均为 $m$ 次待定多项式，$k$ 按 $\lambda + \mathrm{i}\omega$（或 $\lambda - \mathrm{i}\omega$）不是特征方程的根或是特征方程的单根分别取 $0$ 或 $1$。

**注**：上方两个结论均可推广到高阶情形。
